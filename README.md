# Excelフォルダ比較（PowerShell版）

A・Bフォルダの同名Excelファイルを比較し、値・数式・取消線の差分をExcelに出力するWindows用ツールです。

**Python・追加ライブラリ・Excelのインストールは不要です。** Windows PowerShell 5.1とWindows標準の.NET Frameworkだけで動きます。Excelを起動せず、ファイル内のXMLを直接読み書きします。通信やマクロ実行は行いません。

## 使い方

1. このリポジトリをZIPでダウンロードして展開します。
2. 「起動.cmd」をダブルクリックします。
3. Aフォルダ、Bフォルダを順に選択します。
4. 結果の保存先と新しい.xlsxファイル名を指定します。
5. 処理が終わったら、保存されたExcelファイルを開きます。

起動に必要なのは「起動.cmd」と「ExcelCompare.ps1」だけです。結果を閲覧する際にはExcelなどの対応ソフトを使ってください。

PowerShellから直接実行する場合:

```powershell
.\ExcelCompare.ps1 -FolderA 'C:\data\A' -FolderB 'C:\data\B' -OutputPath 'C:\data\result.xlsx' -NoDialog
```

実行ポリシーによって起動できない場合は「起動.cmd」を使ってください。起動時の指定はそのプロセスだけに適用され、PC全体の設定は変更しません。組織のポリシーでPowerShellやAdd-Typeが制限されている場合は、その制限に従ってください。

## 出力

| シート | 内容 |
| --- | --- |
| 比較一覧 | ファイルごとの比較結果、差分行数、エラー・注意点 |
| 差分詳細 | ファイル名、シート名、セル位置、A・Bの値・数式・取消線・保存済み計算結果 |
| 比較条件 | 比較フォルダ、日時、比較方法 |

取消線は「なし」「全体」「一部（文字位置: 2-4, 6）」などで表示します。文字位置は先頭を1とします。

## 比較ルールと制限

- `.xlsx`・`.xlsm`に対応。`.xls`・`.xlsb`は「対象外」と記録します。
- フォルダ直下の同名ファイル（拡張子込み）を対象とし、ファイル名の英字大小は区別しません。
- 同名シートの同じセル位置を比較します。サブフォルダ、行挿入や並べ替えの追跡は対象外です。
- 値・型、数式、保存済み計算結果、直接設定された取消線を比較します。部分的な取消線にも対応します。
- 共有数式はセル位置に合わせて展開して比較します。再計算はせず、計算結果未保存は「保存値なし」と扱います。
- 色・罫線・その他書式、画像・グラフ・コメント・マクロは比較しません。
- 条件付き書式の表示結果や行・列の書式継承は評価しません。該当する取消線設定などを検出した場合は注意を表示します。
- **日付・時刻は原則としてExcel内部のシリアル値で比較・表示します。** A・Bの日付システムが違う場合は注意を表示します。
- 文字の英字大小、空白、改行、数値と文字列、空白とゼロを区別します。数値の許容誤差は設けません。
- 片方だけのシートは1行にまとめます。暗号化・破損ファイルやWhat-Ifデータテーブルなどはエラーとして記録します。
- 元ファイルは読み取り専用で開き、変更しません。既存の出力ファイルも上書きしません。
- 大きいファイルはメモリや処理時間を多く使います。1つのXML部品の上限は256Mi文字です。結果はExcelの行数・セル文字数上限に従います。

## テスト

追加ライブラリなしで実行できます。テスト用ファイルと結果は`work/`に作成します。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Test-ExcelCompare.ps1
```

全体・部分・空セルの取消線、共有数式、文字・数値・真偽値、保存済み計算結果、片方だけのファイル・シート、破損ファイル、条件付き書式の注意、上書き防止、入力ファイルの非変更を確認します。

## 実装

`ExcelCompare.ps1`内で比較処理をC#として定義し、Windows標準の`Add-Type`でメモリに読み込みます。外部のDLL、コンパイラー、パッケージのダウンロードやインストールは行いません。

以前のPython版はGitの履歴に残っています。現在の版はPowerShell版です。
