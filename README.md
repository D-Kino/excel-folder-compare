# Excelフォルダ比較

A・Bフォルダの同名Excelファイルについて、同名シート・同じセル位置の値、数式、保存済み計算結果、取消線を比較し、差分をExcelに出力するWindows向けツールです。Excelの自動起動や通信は行いません。

## 利用方法

Python 3.12とTkinterが利用できる環境で実行します。

```console
python -m pip install -r requirements.txt
python app.py
```

画面でAフォルダ・Bフォルダ・結果の保存先を選び、「比較する」を押してください。

コマンドラインからも実行できます。

```console
python app.py --a "C:\data\A" --b "C:\data\B" --out "C:\data\result.xlsx"
```

配布ZIPには実行環境を同梱しているため、展開して「起動.cmd」を開けば利用できます。Gitには実行環境や比較元のExcelファイルは含めません。

## 比較対象

- `.xlsx`・`.xlsm`。`.xls`・`.xlsb`は「対象外」と記録します。
- フォルダ直下の同名ファイル。拡張子を含めて照合します。
- 値・型、数式、保存済み計算結果、直接設定された取消線。
- セル全体の取消線と、文字の一部の取消線。

## 制限

- サブフォルダ、行挿入や並べ替えの追跡は対象外です。
- 色・罫線などの書式や画像・グラフ・コメント・マクロは比較しません。
- 条件付き書式による取消線や行・列の書式継承は評価しません。検出時は注意を表示します。
- 数式は再計算せず、ファイルに保存された結果を比較します。
- 暗号化・破損ファイルやWhat-Ifデータテーブルなどはエラーとして記録します。
- 入力ファイルは変更しません。既存の出力ファイルも上書きしません。

詳しくは「使い方.txt」を参照してください。

## テスト

```console
python test_compare.py
```

テストデータは無視対象の`work/`に作成します。比較・出力・再読み込み・入力の非変更・上書き防止と、GUIの起動を確認します。GUIが利用可能な環境で実行してください。
